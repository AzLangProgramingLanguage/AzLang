# QBE Intermediate Representation

AzLang compiles code through **QBE** (Quick Backend), a lean intermediate representation compiler providing high code quality without the massive overhead and gigabyte dependencies of LLVM.

---

## 1. Why QBE?

QBE was chosen because it aligns with AzLang's minimalist engineering doctrine:
- **Fast Execution**: Compiles IR to native assembly in microseconds.
- **Small Footprint**: The entire QBE binary is less than 300KB.
- **Readable IR**: QBE intermediate language (`.il`) is human-readable and clean.

---

## 2. Sample QBE IR Emission

Here is the exact intermediate representation generated by AzLang for entry code (`main.il` / `ssample.il`):

```qbe
data $str0 = { b "Hello World", b 0 }

export function w $_start() {
@start
    call $write(l 1, l $str0, l 11)
    call $exit(w 0)
    ret
}
```

AzLang generates this directly from the validated AST, translating function calls to `call $<symbol>(...)` and string constants into `.data` declarations.
